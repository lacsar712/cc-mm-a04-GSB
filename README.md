# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 峰值册

- 每个测点在本班次维护一条峰值记录，只升不降：新上报浓度更高才刷新峰值；更低时峰值不动，但低值行仍写入总表。
- 峰值册展示：测点、当前峰值、对应班测主键（readings.id）。
- 改正某条历史浓度（总表行内“改正”，仅检查员）后，峰值册按该测点现存全部班测重算（`MAX` + 最早主键），峰值可能回落；不存在任何手工修改峰值的接口。
- 旁观账号（viewer）可在顶栏“峰值册”入口只读查看，不能上报、改正或改峰值。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 顶栏点“峰值册”：对东翼-12 先报 0.6 再报 0.4，峰值册仍是 0.6（指向 0.6 那条班测主键），且 0.4 已进总表。
5. 在总表把那条 0.6 行内改正成 0.3，峰值册自动重算，峰值落到仍存在的最高值 0.4，主键改指 0.4 那条。
6. viewer 账号只能看峰值册，上报/改正均被拒绝（403）。
